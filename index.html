01 — Diseño gráfico & branding

Una marca que se ve tan bien como trabaja.

Abre cada tarjeta para ver todo lo que puede incluir tu proyecto.

✦01 / la base de todoIdentidad de marca＋

Antes de vender, tu marca tiene que verse como un negocio real, no como algo improvisado.

  • Logo (simple o con variantes)
  • Paleta de colores + tipografías
  • Kit de Identidad de Marca — incluye: logo principal + 2 variantes, paleta de colores con códigos, 2 tipografías definidas y mini manual de uso (1-2 páginas)
  • Rebranding — para cuando ya tienes marca pero sientes que ya no te representa
  • Moodboards / guías de estilo visual
◌02 / contenido que detiene el scrollRedes sociales＋

La primera impresión de un cliente casi siempre es tu Instagram. Que valga la pena.

  • Stories individuales o en paquete
  • Posts para feed
  • Carruseles informativos/educativos
  • Portadas de highlights
  • Calendario de contenido (planeación visual)
  • Kit de Redes — incluye: 5 plantillas editables (stories/posts), portada de highlights y calendario de contenido del mes
  • Overlays y paneles para streaming/creadores de contenido
  • Miniaturas que sí generan clics — thumbnails llamativos para YouTube/Twitch
  • Banners de perfil — para X, YouTube, Twitch o Facebook, listos para usar
  • Fotos de perfil con estilo — avatares o fotos editadas con la identidad de tu marca
  • Copys que enganchan — textos cortos y persuasivos para tus captions y CTAs
  • Anuncios pagados (Meta Ads) — piezas estáticas listas para pauta en Instagram/Facebook
  • Emotes y stickers para Twitch/Discord — para comunidades de streaming
  • GIFs y stickers para WhatsApp — contenido animado corto y fácil de compartir
  • QR personalizados con tu marca — hasta un código QR se ve como parte de tu identidad
  • Plantillas editables (Canva u otro) — para cuando quieras publicar tú misma sin depender de un diseñador
◇03 / que sí dan ganas de exponerPresentaciones y material educativo＋

Ideal para estudiantes y profes: material que se ve bien y se entiende mejor.

  • Presentaciones para tareas y exposiciones del colegio, con diseño temático, listas para editar
  • Presentaciones para clases (estilo elegante, a medida del tema)
  • Plantillas de clase reutilizables
  • Fichas/worksheets
  • Infografías
  • Guías de estudio visuales — resúmenes de temas convertidos en piezas fáciles de repasar
⌁04 / para quienes cuentan historiasEditorial＋
  • Rediseño de portadas de libros
  • Diagramación de documentos (PDFs, e-books)
  • Catálogos y menús de productos/servicios
  • Maquetación de revistas o fanzines pequeños
✉05 / los detalles que se notanPapelería y aplicaciones＋
  • Tarjetas de presentación (digitales)
  • Firmas de WhatsApp/email
  • Invitaciones y tarjetas para eventos
  • Portafolio/web personal (landing simple)
  • Menús o listas de precios diseñados (como este mismo catálogo)
⌘06 / para negocios que quieren dar el salto digitalUI/UX＋
  • Mockups y prototipos de interfaces (Figma)
  • Diseño de pantallas para apps/webs
  • Rediseño de una pantalla o flujo que ya tienes pero no está funcionando
✒07 / el toque que nadie más tieneIlustración y decoración＋
  • Ilustraciones de línea (ornamentos, íconos temáticos)
  • Sets de decoraciones a juego con la marca
  • Recursos descargables (wallpapers, planners imprimibles)
  • Stickers o elementos gráficos personalizados para WhatsApp/redes
▱08 / packagingPackaging＋
  • Diseño de etiquetas simples
  • Diseño de bolsas o empaques simples para productos físicos
